## `match.html` UI/UX 리뷰 (2026-09-12)

**UI**: 헤더만 `index.html`과 통일, 본문은 `<pre>` 모노스페이스 텍스트 덩어리라 폰트·색상·위계가 안 이어짐.
**UX**: 프로필 입력~제출은 6~8번으로 양호하나, 결과 화면에서 JSON을 직접 읽어야 해 목표 달성이 사실상 불가능.

**문제 5개 (심각한 순)**
1. JSON을 그대로 보여줘 일반 사용자가 매칭 결과를 읽을 수 없음 — 카드 UI로 해결 예정(미착수)
2. 매칭 0건일 때 안내 없음
3. 결과 화면에서 프로필 수정으로 돌아가는 링크 없음
4. 정렬 순서(관심사 겹침순)의 근거를 화면이 설명 안 함
5. 위계 없는 텍스트 덩어리라 어디부터 볼지 안내 없음 — 카드 UI로 해결 예정(미착수)

**즉시 반영(30분 내)**: 2·3·5는 문구/링크 한 줄 추가로 처리 — 0건 안내, `index.html` 링크 상시 노출, "관심사가 많이 겹치는 순" 문구. 1·4는 카드 UI 설계가 필요해 다음 단계로 남김.
