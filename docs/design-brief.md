## My Feed 디자인 방향 (2026-09-30)

매거진형(첫 카드 크게 + 나머지 컴팩트)에서 **인스타그램식 단일 컬럼 포스트 피드**로 교체했다.
카드뉴스 서비스라는 정체성을 피드 화면에서부터 익숙한 형태로 보여주기 위해서다.

- **레이아웃**: 단일 컬럼(폭 520px 제한, 데스크톱에서도 가운데 한 줄). 2열 그리드는 폐지.
- **포스트 구성**: 작성자 줄(로고 + "polistagram", 부제 없음) → 표지 → 캡션.
- **표지**: 4:3 가로형. 배지("나에게 관련 있어요")는 왼쪽 위, **아이콘 → 제목**은 왼쪽 아래에 붙인다.
  제목은 2rem 굵게, 최대 3줄(`line-clamp`), 단어 중간에서 끊기지 않게(`word-break: keep-all`).
  1:1은 세로가 길고 비어 보여 4:3으로 낮췄다.
- **캡션**: 개인화 문구 + 해시태그. 카드 장수는 작성자 줄 오른쪽에 "1/N"으로 표시한다.
- **동작**: 포스트 클릭/Enter → Story View. 키보드 포커스 링 제공.
- **출처 표기**: 작성자는 서비스명(polistagram)이지만, Story View 마지막 카드에는 실제 출처("금융위원회 보도자료")를 유지한다.

## 검증 (2026-09-30)

- 1400px / 390px 두 폭에서 포스트가 항상 한 컬럼(같은 x좌표), 가로 스크롤 없음 확인.
- 남은 리스크: 제목이 3줄을 넘으면 말줄임 처리로 잘림 — 실제 데이터의 제목 길이 분포는 미확인.

## 해결된 이슈 (2026-09-12 리뷰 기준)

`match.html`이 원본 JSON을 그대로 출력하던 문제(위계 없는 텍스트 덩어리)와 매칭 0건 안내는
카드 피드 UI와 Story View로 해소됐다. 아직 남은 것: 피드에서 프로필 수정으로 돌아가는 링크가 없고
(프로필이 없을 때만 `index.html` 링크가 뜸), 정렬 기준(관심사 겹침순)을 화면이 설명하지 않는다.
